# VLR.GG Mobile v2.1 — Hallmark 수정

> **Status:** 2026-09-22에 작성한 미채택 제안 시안의 검토 기록이다. 현재 앱의 디자인 권한은 루트 [DESIGN.md](../../DESIGN.md)에 있다.

대상: `vlrgg-mobile-v2.pen` (저장소에 포함되지 않은 외부 로컬 Pencil 자료). 기존 360dp 화면과 411dp QA를 유지하며 재사용 컴포넌트부터 수정했다. 앱·서버 구현은 이 기록의 범위에 없다.

## 변경 기준

1. Lucide 아이콘을 Google Material Symbols Outlined 원본으로 교체한다. 모양과 패스를 수정하지 않는다.
2. 반복되는 둥근 경기 카드, 선택 배경 타일, 가짜 OS 표시, 장식용 영문 라벨을 걷어낸다.
3. 한국어 본문은 Noto Sans KR, 스코어·브랜드는 Barlow Condensed로 위계를 나눈다. 경기 행은 밀도를 높이고 이름과 숫자의 열을 고정한다.
4. 상태·포커스·즐겨찾기 실패 복구를 유지한다. 화면 이동, 서버 계약, 기능 범위는 변경하지 않는다.
5. 전체 화면의 아이콘 라이브러리, 가시 영역, 360/411dp 폭, 큰 글꼴, 대비를 확인한다.

## Hallmark 검토 범위

Hallmark의 redesign, anti-pattern, interaction/state, slop-test 기준을 당시 `.pen` 결과의 자기 검토에 참고했다. 이는 제안 시안 기록이며 현재 제품 계약의 채택을 뜻하지 않는다.

기존 모바일 앱의 정보 구조를 유지했다. 웹 랜딩 페이지용 macrostructure 교체, CSS·DOM·반응형 브라우저 게이트는 `.pen` 산출물에 해당하지 않는다. 색과 서체는 Pencil 변수와 이 문서에 기록했다.

## 데이터 근거

- 기사 제목·작성자: `.omx/evidence/design-ui-20260921/news-response.json`의 실제 API 캡처.
- 완료 경기: 같은 경로의 `match-results-response.json`. 팀·대회 ID가 null인 항목에 임의 이동을 추가하지 않는다.
- 로컬 fixture의 선수 통계는 실제 최신 기록이 아니다. 근거 없는 숫자와 기사 본문을 사실처럼 표시하지 않는다.
- 정상·오류·빈 상태의 조합은 레이아웃 검증 시나리오다.

## 검증

- 82개 제품 프레임 + 5개 QA 프레임 유지. 제품 폭 360dp, QA 3개는 411×914dp, 나머지는 130% 글꼴·긴 이름 검증이다.
- 22개 재사용 컴포넌트, 39개 변수, 582개 인스턴스. 모든 773개 아이콘 노드(숨김 포함)가 Material Symbols Outlined / 400을 참조한다. 가시 아이콘은 462개다. 자체 패스 아이콘은 추가하지 않았다.
- 가시 노드의 레이아웃 경고 0, 최상위 프레임 겹침 0, 미완료 placeholder 0.
- 모든 글꼴·색상 참조는 변수로 통일했다. Noto Sans KR와 Barlow Condensed 두 서체를 사용한다.
- 가시 텍스트·아이콘의 전경/배경 18개 조합 대비 검사 통과. 기본 본문 15.58:1, 보조 본문 5.66:1, 빨강 5.36:1, 사용 불가 글자도 4.53:1이다.
- 기본 5탭, 검색, 경기/뉴스/팀/선수/대회 상세, 오류 다이얼로그, 즐겨찾기 복구, QA 5개와 컴포넌트 보드를 Pencil 렌더로 확인했다.
- 당시 실행: `python3 .omx/evidence/design-v2.1-20260922/verify_snapshot.py` → PASS. 원본 스냅샷과 결과가 있던 경로는 저장소에 포함되지 않은 외부 로컬 역사 자료다.
- 앱 코드는 변경하지 않았으므로 Gradle 테스트·실기기 접근성·동적 상호작용은 실행하지 않았다. 캔버스 검증은 앱 구현 검증을 대신하지 않는다.

## 최종 Hallmark 검토

`Hallmark · pre-emit critique: P4 H4 E4 S4 R5 V4`

둥근 경기 상자와 선택 타일, LATEST 라벨, 모노그램 대체 로고, 가짜 상태바·홈 표시를 제거했다. 목록은 구분선, 스코어는 condensed 서체, 선택은 원본 아이콘과 글자·색으로 표현한다. 버튼·검색창의 8개 상태를 명시했다. 통계는 명시한 parser fixture의 수치 또는 결측값을 사용한다. 캡처가 없는 기사 본문은 자리표시로 구분했다. 나머지 예정·라이브·오류 화면의 대진·시각 조합은 상태 검증 예시이며 실제 최신 경기 정보가 아니다.

Hallmark의 웹 CSS/DOM, 랜딩 페이지 macrostructure, 브라우저 반응형 폭·모션·focus 이벤트 게이트는 이번 정적 네이티브 앱 `.pen`에 해당하지 않는다. 360/411dp와 130% 글꼴은 사용자 요구를 우선한다. 모든 웹 게이트를 통과했다는 의미로 보고하지 않는다.
