> **Status:** 2026-09-22에 작성한 미채택 제안 시안 기록이다. 현재 앱의 디자인 권한은 루트 [DESIGN.md](../../DESIGN.md)에 있다.

편집 원본: `vlrgg-mobile-v2.pen` (저장소에 포함되지 않은 외부 로컬 Pencil 자료)

## 결과

- **360dp 기준** 제품 화면·상태·콘텐츠 예시 82개.

- **360dp** 추가 검증 2개: 뉴스 글꼴 130%, 긴 팀·대회 이름.
- 방향, Foundations, Components, Patterns, Controls, Source review의 보드 6개.
- 재사용 컴포넌트 22개, 색상·서체·타입 크기·간격 변수 35개.
- 새 시각 제안은 [v2.1 디자인 시스템 제안](v2.1-design-system.md)에 보존했다. 이번 보관 작업은 루트 `DESIGN.md`와 앱·서버 구현을 변경하지 않는다.

## 개선 판단과 반영

| 관측 또는 제한 | 디자인 결정 |
| --- | --- |
| Stitch 외부 리소스 크기와 실제 앱 크기가 혼용됨 | 사용자 지시에 따라 원본 360dp, 확장 확인 411dp |
| 실제 앱에서 탭별 헤더 위치가 다름 | 하나의 56dp 헤더와 안전영역 소유 규칙 |
| 하단 탐색의 보라색 배경·큰 선택 표시가 정보보다 강함 | 흰 바탕, 얇은 상단 선, 작은 빨간 선택 배경, 항상 보이는 라벨 |
| 경기의 상태·시간·팀·스코어·대회가 비슷한 비중 | 일정/상태 → 두 팀/숫자 → 보조 대회 문맥으로 계층 분리 |
| Figma QA에서 행 높이 부족으로 텍스트가 가려짐 | 콘텐츠 기반 행 크기, 연결된 원본 컴포넌트, 실제 bounds와 인스턴스 검사 |
| 영문 상태·날짜·raw ISO 문자열 혼용 | 한국어 UI 라벨, 한 번의 현지 시각 표기, 공식 이름·기사 원제 유지 |
| 작은 보조 텍스트의 가독성 | 13sp 보조, 16sp 본문 중심; 어두운 보조 색상으로 대비 강화 |
| 실패가 화면 전체로 번질 위험 | 페이지네이션 하단 복구, 대회 탭별 복구, 로컬 즐겨찾기 rollback |
| 오래된 MyPage 알림·Next Matches와 경기 벨 | 현재 범위에서 제외하고 Team/Player 즐겨찾기에 집중 |
| 통계의 긴 이름·결측값·가로 이동 | 정체성 열 고정, 지표 순서 유지, 숫자 정렬, `—`와 0 구분 |
| 구현과 시안의 데이터 차이 | 경기 목록 로고 미사용, 이미지 대체 표시, 맵 진행 상태 추정 제거 |

기사·경기·스탯의 내용은 레이아웃 검증용 샘플이다. 실제 서비스에서는 API가 제공하는 값만 사용한다.

## 전체 화면 범위

프레임 이름 앞 번호로 캔버스에서 계열을 찾을 수 있다. 기본 화면은 왼쪽, 상태 변형은 오른쪽에 배치했다.

| 계열 | 수 | 포함 |
| --- | ---: | --- |
| 뉴스 목록 | 5 | 정상, 로딩, 빈 목록, 초기 오류, 추가 로드 오류 |
| 뉴스 상세 | 5 | 정상, 로딩, 본문 없음, 오류, 선택 블록 누락의 정상 본문 예시 |
| 경기 목록 | 6 | 예정/LIVE, 결과, 로딩, 빈 목록, 결과 오류, 추가 로드 오류 |
| 경기 상세 | 9 | 예정, LIVE, 종료, 연기, 취소, 로딩, 오류, 부분 오류, 확인 불가 |
| 대회 목록 | 5 | 정상, 로딩, 빈 목록, 오류, 예정 그룹만 없음 |

기존 Stitch 88개에서 Match 알림 관련 6개를 현재 범위에서 제외했다. 과거 MyPage 14개를 현재 계약의 11개로 재구성하고, 연기·취소·대회 일부 그룹 없음 3개를 보강했다. News의 선택 블록 누락은 별도 Partial 런타임 상태가 아니다.

## 디자인 시스템과 소유권

- 보드 `00–05`: 방향과 근거, 토큰, 연결된 컴포넌트, 상세 패턴, 컨트롤 상태.
- 화면 `10–39`: 기본 탐색과 정상 상세.
- 화면 `40–51`: 오류·빈 상태·로딩·즐겨찾기 등.
- 화면 `60–62`: 411dp, 글꼴 확대, 긴 이름 검증.
- 원본 컴포넌트를 변경하면 연결된 인스턴스에 반영된다. 세부 텍스트와 상태는 override로 구분했다.
- 외부 로컬 `.pen` 옆 `vlrgg-mobile-v2-assets/`에는 비교 보드의 원본 참고 PNG가 있다. 해당 자료는 저장소에 포함되지 않으며 원본 파일을 이동할 때 함께 보관한다.
- 모든 화면은 편집 가능한 벡터·텍스트·프레임이다. Source review의 원본 캡처만 이미지다.
- .pen의 정적 화면은 실행 가능한 앱이나 전환 프로토타입이 아니다.

## 검증

- 전체 화면과 재사용 인스턴스의 bounds, 표시되는 콘텐츠의 잘림, 최상위 프레임 겹침을 검사했다.
- 130% 글꼴에서 마이페이지 탐색 라벨이 넘치는 문제를 찾아 2줄 라벨과 높이 확장으로 수정했다.
- 뉴스의 마지막 행 넘침, 대회 상태 칩의 불필요한 전체 폭, 상세 헤더의 불필요한 저장 라벨을 수정했다.
- 전체 화면 계열의 대표 렌더와 재시도·즐겨찾기 오류·통계·411dp·큰 글꼴·긴 이름 렌더를 확인했다.
- 일반 텍스트 대비: Ink 17.30:1, Muted 5.56:1, Red 5.59:1. 예정 6.34:1, 종료 6.19:1, 연기 6.05:1.
- 숨긴 재시도 버튼처럼 `enabled=false`인 노드의 이전 bounds는 표시 콘텐츠 검사에서 제외한다.
- 저장된 검증 JSON은 파일·노드 목록과 실제 검사 결과를 기록한다. 렌더와 구조 검사는 실기기 접근성 검증을 대체하지 않는다.
- 디자인·문서 작업이므로 Gradle 빌드와 앱 테스트는 실행하지 않았다.

## 남은 구현 검증

- 실제 API 데이터·이미지, 다양한 locale/timezone, 플랫폼별 safe area.
- 200% 이상 글꼴과 TalkBack/VoiceOver.
- 키보드 초점, 통계 가로 스크롤·정렬, 탭/스크롤 복원, 스낵바 알림.
- 새 토큰을 현재 Compose theme에 적용하는 별도 구현 작업.
